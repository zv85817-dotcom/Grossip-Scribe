# Player Grossip

Read [WORKFLOW_PROMPT.md](WORKFLOW_PROMPT.md) for the full workflow. A clear topic, link, or recognizable screenshot is enough to start a complete episode. Verify the story and its aftermath, write separate Chinese and English drafts, source real photos, create both covers, and validate and package the results. If the user asks for one item, specific photo numbers, or a revision to a previous cover, limit the work to that request.

- Use `Player Grossip` as the series name and `PLAYER GROSSIP` on covers. Tell the story as you would to a friend: build suspense around details you can verify.
- Export PNG covers at **1920×1080** landscape and **522×652** portrait, measured width by height. Compose the portrait separately.
- Open both final images before packaging. If Python 3 is available, run [check_covers.py](scripts/check_covers.py) with `--bundle ... --full` for a complete episode. Use equivalent checks if the script cannot run.
- Read the [production guide](references/production.md) for sourcing images, generating covers, exporting exact dimensions, or updating an existing ZIP. Use the tools available in the current session and follow their instructions.
- Upload, post, or push files only when requested.
